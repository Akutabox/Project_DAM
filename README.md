\# Project DAM

\## Akuisisi dan Manajemen Data



Repository ini berisi hasil praktikum mata kuliah Akuisisi dan Manajemen Data (BIFP-243).



\### Tujuan

Mempelajari proses akuisisi, pengelolaan, penyimpanan, dan dokumentasi data.



\### Struktur Folder

\- data/: penyimpanan data

\- notebooks/: notebook praktikum

\- src/: kode program

\- docs/: dokumentasi

\- reports/: laporan praktikum

\- logs/: catatan proses



\### Praktikum

Modul 01 - Pengantar Data Acquisition and Management.
